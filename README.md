# 简历投递记录系统

## 概述

这是一个基于 OCR 与大模型（LLM）技术的简历投递记录自动归档工具[cite: 4]。通过对招聘软件的岗位详情进行截图，系统会自动提取纯文本，调用大模型精准结构化解析（如公司名、城市、岗位等），并自动查重、更新到 Excel 表格中，最后对截图进行重命名归档[cite: 4]。

## 环境要求

- **Python 3.10**（必须为 3.10 以保证 PaddlePaddle 的完美兼容）[cite: 4]
- Windows 10/11[cite: 4]
- 需配置大模型 API 密钥（默认支持讯飞星辰 MaaS，或其他 OpenAI 兼容接口）[cite: 4]

## 快速开始

### 1. 首次安装与环境配置

```bash
# 创建 Python 3.10 虚拟环境
uv venv .venv --python 3.10

# 激活虚拟环境
.venv\Scripts\activate

# 安装核心依赖
uv pip install paddlepaddle==2.6.2 paddleocr==2.8.1 openpyxl python-dotenv openai

```

### 2. 配置环境变量

在项目根目录下创建一个 `.env` 文件，填入你的大模型接口配置（以讯飞星辰 MaaS 为例）：

```env
OPENAI_API_KEY=你的API_Password
OPENAI_BASE_URL=[https://maas-coding-api.cn-huabei-1.xf-yun.com/v2](https://maas-coding-api.cn-huabei-1.xf-yun.com/v2)
LLM_MODEL=astron-code-latest

```

### 3. 使用脚本

系统已重构为模块化架构，入口文件现为 `main.py`。建议在项目根目录新建 `简历投递记录/` 文件夹用于存放日常投递截图。

#### 批量全自动模式（推荐工作流）

```bash
# 批量处理目录下的所有截图，处理完后自动移动至“已归档截图”目录
python main.py --batch ./简历投递记录/

# 批量预览（显示识别结果但不写入Excel，不移动文件）
python main.py --batch ./简历投递记录/ --dry-run

```

#### 单文件模式

```bash
# 全自动模式：大模型提取 + 确认步骤
python main.py 简历投递记录/截图.png --auto

# 手动交互式模式：完全不调用大模型，手动输入所有字段
python main.py 简历投递记录/截图.png

```

## 核心功能特性

### 1. 大模型智能提取



摒弃了脆弱的正则匹配，全面接入大模型进行语义理解。自动识别并约束输出以下字段格式：

| 字段 | 识别方式 | 示例 |
| --- | --- | --- |
| 公司 | LLM 语义推理 + 严格提取 | 华为技术有限公司 |
| base（工作地点） | LLM 提取清洗 | 郑州、北京、上海 |
| 行业 | LLM 归纳 | 人工智能/智能制造 |
| 投递志愿与顺序 | LLM 提取清洗 | AI算法工程师 |
| 当前进度 | 默认值设定 | 投递 |
| 对应日期 | 自动获取当前日期 | 2026-08-15 |
| 备注 | LLM 核心要点归纳 | 硕士及以上、熟悉Python |

### 2. 智能查重与拦截

在写入 Excel 前，系统会自动对主表进行联合查重检查。

* **匹配规则**：当截图中识别出的 `公司` + `base` + `岗位` 三要素在主表中已存在时，判定为重复投递。
* **触发效果**：系统将在终端提示跳过写入，并将截图直接移动归档，防止 Excel 产生脏数据。

### 3. 交互控制与降级保护

在每张图片处理完成后，系统会暂停等待用户操作：

| 按键 | 效果 |
| --- | --- |
| Y / 回车 | 确认信息无误，继续写入 Excel |
| m | **手动修改**：逐项微调大模型识别有误的字段 |
| n | 跳过当前图片，不写入记录 |
| s | 跳过所有剩余图片 |
| q | 退出批量处理 |

*注：如果大模型未能成功识别到“公司”名称，系统将强制跳过确认，自动降级进入 `[m]` 手动补全模式。*

### 4. Excel 文件防占用保护

当脚本尝试向 Excel 写入数据时，如果检测到 `简历投递记录.xlsx` 正在被其他软件（如 WPS/Office）打开并占用，脚本不会崩溃退出，而是会在终端抛出警告，等待用户关闭文件后按回车重试。

## 文件与目录结构

* **主入口**: `main.py` - 参数解析与流程调度
* **配置文件**: `config.py` - 集中管理环境变量与 Excel 路径/表头
* **提取引擎**: `extractor.py` - 负责 OCR 文字提取与 LLM API 交互
* **数据存储**: `excel_handler.py` - 包含防占用重试与查重机制的 Excel 写入逻辑
* **工具箱**: `utils.py` - 终端交互与图片整理归档
* **Excel数据**: `简历投递记录.xlsx` - 主数据文件（含主表和附表）


* **图片归档**: `已归档截图/` - 处理成功的截图将被移动至此，并自动重命名为 `公司_地点_职位_原始文件名.png`

## 附表自动同步

每次向主表新增投递记录时，系统会自动将数据同步到【附表】进度更新：

* **匹配规则**：根据 `公司` + `岗位名称` + `阶段` 判断是否已存在记录


* 如存在 → 仅更新对应的日期列


* 如不存在 → 新增一行完整的事件记录





## 注意事项

1. 首次运行会下载 PaddleOCR 基础模型（约 200MB），需要耐心等待


2. 截图应尽量清晰，包含完整的公司名、地点与岗位信息


3. 确保 `.env` 中的大模型 API 余额/额度充足，若接口调用失败将自动切入纯手动输入模式。
